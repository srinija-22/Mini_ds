                                STUDENT RECORD MANAGEMENT SYSTEM

A menu-driven Student Record Management System developed in C using a Singly Linked List. 
The project allows users to add, delete, display, modify, sort, reverse, and save student records through a simple command-line interface.

# Project Files
main.c - Main function and menu-driven program flow.
header.h - Structure definitions, function prototypes, and header declarations.
stud_add.c - Adds student records and assigns the smallest available roll number.
stud_del.c - Deletes student records by name or roll number.
styd_show.c - Displays all student records.
stud_modify.c - Modifies student details using roll number, name, or percentage.
stud_sort.c - Sorts student records by name or percentage.
stud_ReversLinks.c - Reverses the linked-list links.
stud_delAll.c - Deletes all nodes and frees allocated memory.
countnode.c - Counts the total number of nodes in the linked list.
stud_Save.c - Saves student records to student.dat.
stud_data.c - Contains sample student record data.
